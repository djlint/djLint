La configuration se fait dans le fichier `pyproject.toml` de votre projet, dans un fichier `djlint.toml` ou `.djlint.toml`, ou dans un fichier `.djlintrc`. Les arguments de la ligne de commande ont toujours priorité sur les réglages des fichiers de configuration. Les réglages locaux du projet ont priorité sur un fichier de configuration global passé avec `--configuration`, sauf si `--prefer-configuration` est indiqué.

djLint cherche ces fichiers en remontant depuis le premier chemin qu'il vérifie (pour `-`, depuis le dossier de `--stdin-filename`, ou depuis le répertoire courant sans cette option). Il s'arrête au premier dossier qui contient un `djlint.toml`, un `.djlint.toml`, un `.djlintrc`, un `.djlint_rules.yaml` ou un `pyproject.toml` avec `[tool.djlint]`, et ne remonte jamais au-delà de la racine d'un dépôt (un dossier avec un dossier ou un fichier `.git`, ou un dossier `.hg`). Un `pyproject.toml` sans réglages djLint ne l'arrête pas, donc un paquet d'un monorepo avec son propre `pyproject.toml` reçoit les réglages du dépôt. djLint ne lit que le dossier où il s'arrête : `[tool.djlint]` dans son `pyproject.toml` si cette table définit quelque chose, sinon son `djlint.toml` ou `.djlint.toml`, sinon son `.djlintrc`, et signale ceux qui s'y trouvent sans être lus.

Quand ni la ligne de commande ni la configuration ne fixent `indent` ou `max_line_length`, djLint prend `indent_size` ou `max_line_length` dans les fichiers `.editorconfig`, comme le font les éditeurs : chaque fichier les reçoit selon son propre chemin, le `.editorconfig` le plus proche l'emporte et ceux du dessus complètent, jusqu'à un fichier avec `root = true` ou jusqu'à la racine du projet.

Le format de `pyproject.toml` est `toml`.

```toml
[tool.djlint]
profile = "django"
ignore = ["H014", "H015"]
```

Le format de `djlint.toml` et `.djlint.toml` est `toml`.

```toml
profile = "django"
ignore = ["H014", "H015"]
```

Le format de `.djlintrc` est `json`.

```json
{ "profile": "django", "ignore": ["H014", "H015"] }
```

Les options à plusieurs valeurs, comme `ignore`, prennent une liste. Une chaîne séparée par des virgules, comme `"H014,H015"`, marche aussi, et c'est ce qu'il faut à djLint avant la 1.41.

Depuis la version 1.51, djLint signale une option ou un code de règle qu'il ne connaît pas, en indiquant le plus proche qu'il connaît.
