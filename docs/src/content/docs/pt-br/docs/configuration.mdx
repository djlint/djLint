A configuração é feita pelo arquivo `pyproject.toml` do seu projeto, por um arquivo `djlint.toml` ou `.djlint.toml`, ou por um arquivo `.djlintrc`. Os argumentos da linha de comando sempre têm prioridade sobre as configurações dos arquivos de configuração. As configurações locais do projeto têm prioridade sobre um arquivo de configuração global informado com `--configuration`, a menos que `--prefer-configuration` esteja definido.

O djLint procura esses arquivos subindo a partir do primeiro caminho que verifica (com `-`, a partir da pasta de `--stdin-filename`, ou do diretório atual sem essa opção). Ele para na primeira pasta que tem uma pasta ou um arquivo `.git`, uma pasta `.hg`, um `pyproject.toml`, um `djlint.toml`, um `.djlint.toml` ou um `.djlintrc`, e lê só essa pasta: `[tool.djlint]` no `pyproject.toml` dela, se essa tabela definir algo; se não, o `djlint.toml` ou `.djlint.toml`; se não, o `.djlintrc`. Assim, um `pyproject.toml` sem configurações do djLint impede que um arquivo de configuração numa pasta acima seja lido.

O formato do `pyproject.toml` é `toml`.

```toml
[tool.djlint]
<config options>
```

O formato do `djlint.toml` e do `.djlint.toml` é `toml`.

```toml
<config options>
```

O formato do `.djlintrc` é `json`.

```json
{ "option": "value" }
```
