La configurazione si imposta nel file `pyproject.toml` del progetto, in un file `djlint.toml` o `.djlint.toml`, oppure in un file `.djlintrc`. Gli argomenti della riga di comando hanno sempre la precedenza su qualsiasi impostazione dei file di configurazione. Le impostazioni locali del progetto hanno la precedenza su un file di configurazione globale indicato con `--configuration`, a meno che non sia impostato `--prefer-configuration`.

djLint cerca questi file risalendo dal primo percorso che controlla (con `-`, dalla cartella di `--stdin-filename`, o dalla directory corrente se manca). Si ferma alla prima cartella che contiene una cartella o un file `.git`, una cartella `.hg`, un `pyproject.toml`, un `djlint.toml`, un `.djlint.toml` o un `.djlintrc`, e legge solo quella cartella: `[tool.djlint]` nel suo `pyproject.toml` se la tabella imposta qualcosa, altrimenti il suo `djlint.toml` o `.djlint.toml`, altrimenti il suo `.djlintrc`. Quindi un `pyproject.toml` senza impostazioni di djLint impedisce di leggere un file di configurazione in una cartella superiore.

Il formato di `pyproject.toml` è `toml`.

```toml
[tool.djlint]
profile = "django"
ignore = ["H014", "H015"]
```

Il formato di `djlint.toml` e `.djlint.toml` è `toml`.

```toml
profile = "django"
ignore = ["H014", "H015"]
```

Il formato di `.djlintrc` è `json`.

```json
{ "profile": "django", "ignore": ["H014", "H015"] }
```

Le opzioni con più valori, come `ignore`, accettano una lista. Va bene anche una stringa separata da virgole, come `"H014,H015"`, che è quella che serve a djLint prima della 1.41.

Un interruttore è `true` o `false`. Da djLint 1.51 può essere anche `"yes"` o `"no"`, `"on"` o `"off"`, `"1"` o `"0"`, e djLint avvisa di un'impostazione o di un codice di regola che non conosce, indicando il più vicino che conosce.
