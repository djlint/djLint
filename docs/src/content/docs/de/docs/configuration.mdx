Die Konfiguration erfolgt entweder über die Datei `pyproject.toml` Ihres Projekts, über eine Datei `djlint.toml` oder `.djlint.toml` oder über eine Datei `.djlintrc`. Argumente auf der Befehlszeile haben immer Vorrang vor den Einstellungen in Konfigurationsdateien. Lokale Projekteinstellungen haben Vorrang vor einer globalen Konfigurationsdatei, die mit `--configuration` angegeben wird, es sei denn, `--prefer-configuration` ist gesetzt.

djLint sucht diese Dateien vom ersten geprüften Pfad aus aufwärts (bei `-` vom Ordner von `--stdin-filename`, ohne diese Option vom aktuellen Verzeichnis). Es hält beim ersten Ordner an, der einen Ordner oder eine Datei `.git`, einen Ordner `.hg`, eine `pyproject.toml`, eine `djlint.toml`, eine `.djlint.toml` oder eine `.djlintrc` enthält, und liest nur diesen Ordner: `[tool.djlint]` in dessen `pyproject.toml`, sonst dessen `djlint.toml` oder `.djlint.toml`, sonst dessen `.djlintrc`. Eine `pyproject.toml` ohne djLint-Einstellungen verhindert also, dass eine Konfigurationsdatei in einem übergeordneten Ordner gelesen wird.

Für `pyproject.toml` wird das Format `toml` verwendet.

```toml
[tool.djlint]
<config options>
```

Für `djlint.toml` und `.djlint.toml` wird das Format `toml` verwendet.

```toml
<config options>
```

Für `.djlintrc` wird das Format `json` verwendet.

```json
{ "option": "value" }
```
