Konfigurace se zapisuje buď do souboru `pyproject.toml` vašeho projektu, do souboru `djlint.toml` nebo `.djlint.toml`, nebo do souboru `.djlintrc`. Argumenty příkazového řádku vždy přepíší jakékoli nastavení z konfiguračních souborů. Lokální nastavení projektu má přednost před globálním konfiguračním souborem zadaným pomocí `--configuration`, pokud není nastaveno `--prefer-configuration`.

djLint tyto soubory hledá směrem nahoru od první cesty, kterou kontroluje (u `-` od složky `--stdin-filename`, bez něj od aktuálního adresáře). Zastaví se u první složky, která obsahuje složku nebo soubor `.git`, složku `.hg`, soubor `pyproject.toml`, `djlint.toml`, `.djlint.toml` nebo `.djlintrc`, a čte jen tuto složku: `[tool.djlint]` v jejím `pyproject.toml`, pokud tato tabulka něco nastavuje, jinak její `djlint.toml` nebo `.djlint.toml`, jinak její `.djlintrc`. Soubor `pyproject.toml` bez nastavení djLintu tak zabrání načtení konfiguračního souboru v nadřazené složce.

Soubor `pyproject.toml` je ve formátu `toml`.

```toml
[tool.djlint]
profile = "django"
ignore = ["H014", "H015"]
```

Soubory `djlint.toml` a `.djlint.toml` jsou ve formátu `toml`.

```toml
profile = "django"
ignore = ["H014", "H015"]
```

Soubor `.djlintrc` je ve formátu `json`.

```json
{ "profile": "django", "ignore": ["H014", "H015"] }
```

Volby s více hodnotami, například `ignore`, berou seznam. Funguje i řetězec oddělený čárkami, například `"H014,H015"`, který potřebuje djLint starší než 1.41.

Přepínač je `true` nebo `false`. Od djLint 1.51 může být i `"yes"` nebo `"no"`, `"on"` nebo `"off"`, `"1"` nebo `"0"` a djLint upozorní na nastavení nebo kód pravidla, které nezná, a nabídne nejbližší známé.
