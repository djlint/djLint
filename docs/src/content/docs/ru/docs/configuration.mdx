Настройка выполняется через файл `pyproject.toml` вашего проекта, файл `djlint.toml` или `.djlint.toml` либо файл `.djlintrc`. Аргументы командной строки всегда переопределяют настройки из файлов конфигурации. Локальные настройки проекта переопределяют глобальный файл конфигурации, заданный через `--configuration`, если не указан `--prefer-configuration`.

djLint ищет эти файлы вверх от первого проверяемого пути (для `-` от папки из `--stdin-filename`, а без этого параметра от текущего каталога). Поиск останавливается на первой папке, где есть папка или файл `.git`, папка `.hg`, файл `pyproject.toml`, `djlint.toml`, `.djlint.toml` или `.djlintrc`, и читается только эта папка: `[tool.djlint]` из её `pyproject.toml`, если в этой таблице что-то задано, иначе её `djlint.toml` или `.djlint.toml`, а если нет и их, то её `.djlintrc`. Поэтому `pyproject.toml` без настроек djLint не даёт прочитать файл конфигурации из папки выше.

Файл `pyproject.toml` записывается в формате `toml`.

```toml
[tool.djlint]
<config options>
```

Файлы `djlint.toml` и `.djlint.toml` записываются в формате `toml`.

```toml
<config options>
```

Файл `.djlintrc` записывается в формате `json`.

```json
{ "option": "value" }
```
