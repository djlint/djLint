Настройка выполняется через файл `pyproject.toml` вашего проекта, файл `djlint.toml` или `.djlint.toml` либо файл `.djlintrc`. Аргументы командной строки всегда переопределяют настройки из файлов конфигурации. Локальные настройки проекта переопределяют глобальный файл конфигурации, заданный через `--configuration`, если не указан `--prefer-configuration`.

djLint ищет эти файлы вверх от первого проверяемого пути (для `-` от папки из `--stdin-filename`, а без этого параметра от текущего каталога). Поиск останавливается на первой папке, где есть `djlint.toml`, `.djlint.toml`, `.djlintrc`, `.djlint_rules.yaml` или `pyproject.toml` с `[tool.djlint]`, и никогда не выходит за корень репозитория (папку, где есть папка или файл `.git` или папка `.hg`). `pyproject.toml` без настроек djLint поиск не останавливает, так что пакет в монорепозитории со своим `pyproject.toml` получает настройки репозитория. Читается только папка, где поиск остановился: `[tool.djlint]` из её `pyproject.toml`, если в этой таблице что-то задано, иначе её `djlint.toml` или `.djlint.toml`, а если нет и их, то её `.djlintrc`. О файлах, которые лежат там же, но не читаются, djLint предупреждает.

Если ни командная строка, ни конфигурация не задают `indent` или `max_line_length`, djLint берёт `indent_size` или `max_line_length` из файлов `.editorconfig`, как это делают редакторы: каждый файл получает их по своему пути, ближайший `.editorconfig` главнее, а те, что выше, дополняют его, вплоть до файла с `root = true` или корня проекта.

Файл `pyproject.toml` записывается в формате `toml`.

```toml
[tool.djlint]
profile = "django"
ignore = ["H014", "H015"]
```

Файлы `djlint.toml` и `.djlint.toml` записываются в формате `toml`.

```toml
profile = "django"
ignore = ["H014", "H015"]
```

Файл `.djlintrc` записывается в формате `json`.

```json
{ "profile": "django", "ignore": ["H014", "H015"] }
```

Параметры с несколькими значениями, например `ignore`, принимают список. Строка через запятую вроде `"H014,H015"` тоже работает, а djLint до 1.41 понимает только её.

С версии 1.51 djLint предупреждает о незнакомом параметре или коде правила и подсказывает ближайший известный.
