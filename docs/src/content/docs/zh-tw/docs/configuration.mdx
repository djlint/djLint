設定寫在專案的 `pyproject.toml`、`djlint.toml` 或 `.djlint.toml`，或是 `.djlintrc` 中。命令列選項會覆寫設定檔，但旗標只能開啟選項，因此無法關閉設定檔中開啟的開關。除非設定了 `--prefer-configuration`，否則專案的設定會覆寫以 `--configuration` 指定的全域設定檔。

djLint 會從它檢查的第一個路徑（對 `-` 而言是 `--stdin-filename` 所在的資料夾，未指定時則是目前目錄）往上尋找這些檔案。它會停在第一個含有 `djlint.toml`、`.djlint.toml`、`.djlintrc`、`.djlint_rules.yaml` 或帶有 `[tool.djlint]` 的 `pyproject.toml` 的資料夾，而且不會越過儲存庫的根目錄（含有 `.git` 資料夾或檔案，或 `.hg` 資料夾的資料夾）。沒有 djLint 設定的 `pyproject.toml` 不會讓它停下，因此 monorepo 中有自己 `pyproject.toml` 的套件也會套用儲存庫的設定。djLint 只讀取它停下的資料夾：先讀 `pyproject.toml` 中的 `[tool.djlint]`（其中有設定時），沒有就讀 `djlint.toml` 或 `.djlint.toml`，再沒有就讀 `.djlintrc`；同一資料夾中沒有被讀取的檔案會發出警告。

命令列和設定都沒有設定 `indent` 或 `max_line_length` 時，djLint 會像編輯器一樣從 `.editorconfig` 檔案讀取 `indent_size` 或 `max_line_length`：每個檔案依自己的路徑取值，最近的 `.editorconfig` 優先，上層的檔案補上缺少的值，直到遇到含有 `root = true` 的檔案或到達專案根目錄。

`pyproject.toml` 的格式為 `toml`。

```toml
[tool.djlint]
profile = "django"
ignore = ["H014", "H015"]
```

`djlint.toml` 和 `.djlint.toml` 的格式為 `toml`。

```toml
profile = "django"
ignore = ["H014", "H015"]
```

`.djlintrc` 的格式為 `json`。

```json
{ "profile": "django", "ignore": ["H014", "H015"] }
```

像 `ignore` 這樣有多個值的選項接受清單。也可以寫成以逗號分隔的字串，例如 `"H014,H015"`，djLint 1.41 之前的版本只認得這種寫法。

從 1.51 版起，遇到不認得的設定或規則代碼時，djLint 會發出警告並列出最接近的已知項目。
